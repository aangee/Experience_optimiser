# Experience Optimiser

Ce dépôt rassemble mon parcours d'expérimentation.

Il ne s'agit pas d'une collection de projets "finis", mais d'un espace où j'explore des idées, des concepts et des techniques afin de mieux comprendre leur fonctionnement.

On y retrouve notamment :

- expériences JavaScript
- Canvas 2D
- physique
- fractales
- jeux
- prototypes
- interfaces
- essais techniques

Chaque dossier représente une étape de mon apprentissage et témoigne de l'évolution de ma manière de réfléchir, de développer et de concevoir des solutions.

## Pourquoi ce dépôt ?

Je crois que l'apprentissage ne se résume pas à accumuler des connaissances.

Pour moi, comprendre passe par l'expérimentation, les erreurs, les prototypes et les nombreuses itérations qui permettent progressivement de construire une vision plus cohérente d'un sujet.

Ce dépôt est la trace de cette démarche.
